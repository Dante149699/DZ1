# # ДЗ1 — вариант 2 (B22)
Алгоритм: DFS — поиск в глубину. Язык: Java.

## Состав
`Vertex.java` — вершина; `Edge.java` — ребро; `Graph.java` — граф;
`DFS.java` — обход в глубину; `Main.java` — запуск; `Tests.java` — проверки.

## Запуск
Требуется JDK 8 или новее. Из папки проекта:
```bash
javac -encoding UTF-8 src/*.java
java -cp src Main
```
Проверки:
```bash
java -cp src Tests
```

## Граф варианта
Вершины A, B, C, D, E, F. Неориентированные рёбра веса 1:
A-B, B-C, B-D, B-E, C-E, D-E, E-F.
Соседи рассматриваются по алфавиту.

## Результат
Порядок DFS: A -> B -> C -> E -> D -> F.
Путь A -> F: A -> B -> C -> E -> F.
Количество рёбер: 4.
